# UKL development archives

This folder stores the UKL launcher development ZIP archives and the current friend-launcher build archives.

- `UKLF_friend_build_fixed.zip` is the latest friend-launcher source/build package.
- `UKL_admin_friend_split.zip` contains the administrator/friend launcher split.
- `UKL_modpack_1.20.1.zip` contains the test modpack manifest and downloaded test mods.
- Earlier `UKL_phase*` archives are historical development checkpoints.

The archives do not include Microsoft Client Secrets, passwords, access tokens, or refresh tokens. A Microsoft Client ID is entered locally during the friend build process and is not stored in these archives.
